## Project Overview
- This application provides users with a comprehensive platform to interact with the company, browse products, submit complaints, and learn about the company. The app follows clean architecture principles for maintainability, scalability, and testability.
______________________________________
## Features
1. Contact Us
2. Our Products
3. Submit Complaint
4. About the Company

_____________________________
## Architecture
The application follows Clean Architecture principles with the following layers:

- Presentation Layer - UI components, screens, widgets, and view models
- Domain Layer - Business logic, entities, and use cases
- Data Layer - Repositories, data sources (remote and local)
